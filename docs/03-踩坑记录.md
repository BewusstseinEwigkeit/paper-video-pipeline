# 常见问题

每条写清现象、原因和做法。

## 时间与锚点

| 现象 | 原因 | 做法 |
|---|---|---|
| 改了文案，画面整段错位，卡片对不上旁白 | 画面里写死了秒数（如 `121.4`） | 一律写成 `at()`；`check_anchors.py` 用 WARN 报出写死的秒数 |
| 换文案后几十个锚点同时失效 | 锚点挂在旧文案的词上 | 文案一改就跑 `check_anchors.py`，按新文案的语义逐个重新挂 |
| 某块面板从头到尾压在画面上 | 起点写死成秒数，换时间轴后落到了别的章节 | 改成 `at("r7", undefined, true) + 0.9` 这类写法 |
| 出的静帧还是旧画面 | 类型检查失败，后面的 `&&` 没执行，打包被跳过 | 出图前确认打包成功；备份的 `.tsx` 不要留在工程目录里，否则会被类型检查扫进去 |

## 配音与音频

| 现象 | 原因 | 做法 |
|---|---|---|
| 听起来赶、有“电音”、齿音发糊 | 逐句切开再统一压停顿；多次 MP3 转码 | 按章节整段合成，保留自然停顿，全程 PCM |
| 叮声突兀，背景有电流声 | 合成的音效和低频铺垫 | 不加合成音效，转场只靠配乐在章节间隙里抬起来 |
| 片尾配乐提前断掉 | 配乐比旁白短，被补零 | `mix_all.py` 自动放慢，最多到 0.90 倍；超出就报错 |
| 同样的文案长了约 7% | Gemini 导演提示里没写语速 | 基础提示里写明约每分钟 150 词 |
| 怀疑某个词念错了 | 小型 Whisper 常听错（“Modeling”听成“Marling”） | 用中型 Whisper 复听（`verify_voice.py`）后再下结论 |
| 某一章要改一句 | — | 只重合成那一章（`tts_edge.py … r`），其余章节保留 |

## 画面

| 问题 | 做法 |
|---|---|
| 换了文案，画面没跟上，前面显得重复 | 新句子要有自己的画面，不沿用同一个 3D 镜头加分数面板。背景和问题章按 3D、2D 讲解卡、3D、论文图、卡片的顺序交替 |
| 卡片、字体和装饰细线 AI 味重 | 不用带发光边框的胶囊卡片和粗无衬线字，改用编号、Instrument Serif 斜体和细连接线；装在框里的细条改成无框的点阵分布图 |
| 视频里挂“示意值”“非本系统实测”一类小字 | 不放防御性小字；示意图上不标数字，靠画法本身表明是示意 |
| 论文框架图放大后发糊 | 聊天软件转发的图常被压到 2000 px 左右，要找原图；换图前核对是不是最新版 |
| 合作者给的回放视频 HUD 上写着别的方法名 | 裁掉 HUD，只标数据集名 |

## 内容

| 情况 | 做法 |
|---|---|
| 结尾提到某项指标下降，等于在讲自己的缺点 | 旁白和画面都不出现缺点；网页上的论文原表保留完整列 |
| 网页表格里的数字和论文对不上 | 网页表格逐格对照论文原表，不从别的表抄 |
| 图表标签和旁白用词不一致（同一个基线一处叫 Baseline、一处叫方法名） | 文案改用词时，同步改图表标签 |
| 双盲投稿 | 生成的页面跑一遍禁用词检查：作者名、单位、外部 CDN |

## 交付

| 情况 | 做法 |
|---|---|
| 附件体积有上限（100 MB） | 用 `web_encode.py` 按时长算码率；母片 CRF 16 另外保留 |
| 网站只同步了页面，没同步视频 | 视频文件必须写进上传清单；`publish_ssh.py` 会检查首尾分段请求 |
| 质检报了几秒画面冻结 | 先看帧：卡片停在画面上等旁白念完是正常停留，不用改 |
| 渲染时间 | 5 分钟 1080p 约 16 分钟（并发 4）；迭代只出静帧和样片，全片等确认后再渲 |
| Git Bash 下上传到 `/var/www/...` 失败，远端家目录里多出 `C:/Program`、`Files/Git/...` 两棵空目录 | MSYS 会把参数里的 POSIX 路径改写成 Windows 路径；在 PowerShell 里跑，或者设 `MSYS_NO_PATHCONV=1`。`publish_ssh.py` 遇到带 `:` 或空格的远端路径会直接拒绝 |
