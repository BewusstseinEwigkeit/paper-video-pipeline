# 论文展示视频 · 字体与动效规范

> 2026-11 整理。来源有四个：Remotion 官方 best-practices skill（timing、transitions、effects、light-leaks 几节），另一家模型对样片的设计评审，生成的风格帧，以及三部片子的返工经验。
>
> 模板里已有的实现在 `template/src/film/` 的 `motion.tsx`、`Shell.tsx`、`theme.ts`。下文提到而模板里没有的组件（`BigNumber`、`Gather`、`Tag`、`Leaderboard` 等）是原片里的做法，按需自己实现。

## 1. 高级感从哪里来

| 做法 | 反面 |
|---|---|
| 一套动效语言：缓动曲线、时长和错峰都有名字，全片统一调用 | 每个元素各用各的 ease，有的线性 |
| 同一个对象跨镜头延续：大数字飞进条形末端；画板推近、拉远 | 两个状态之间淡出、淡入，或者切到下一页 |
| 字是"长出来"的：逐词遮罩上浮，由虚到实 | 整块文字淡入，或者弹跳出现 |
| 克制：字重 500–600，少发光，深色底里只有一种主色 | 800 字重、霓虹外发光、默认的 Tailwind 原色 |
| 画面不停：3D 镜头始终轻微漂移，车道线滚动，光点沿轨迹流动 | 静止的幻灯片，坐标轴空等 |
| 声画同步：字幕逐词点亮，关键词着色，数字出现在念到它的那一刻 | 字幕整句死贴在画面上，图表和旁白各走各的 |

## 2. 字体：两个字族加一个点缀

| 角色 | 字体 | 720p 字号 | 字重、宽度、字距 | 备注 |
|---|---|---|---|---|
| 片名 | Mona Sans | 80 | 600 · 108% · −2.4 | 关键词换成 Instrument Serif 斜体，98px，珊瑚红 `#F87171` |
| 大数字 | Mona Sans | 168 | 600 · 112% · −4，等宽数字 | 不加外发光，逐位升起，不做滚动计数 |
| 模块名 | Mona Sans | 38 | 800 · 118% | 后面跟一行 22px、400 字重的全称 |
| 图表标题和标签 | Mona Sans | 22–36 / 20–24 | 500–600 | 数值一律用等宽数字 |
| 3D 内 HUD 标签 | Mona Sans | 15 | 600 · 88% · +0.4 | 深色磨砂底，同色描边，带色点和引线 |
| 3D 内概念词 | Instrument Serif 斜体 | 30 | 400 | 只用在冷开场的一两个核心概念词上 |
| 字幕 | Source Serif 4 | 27 | 400，行高 1.3 | 关键词着色：主对象红，对照对象蓝，方法名和模块名青 `#5FD3E8`，数字加粗 |
| 章节进度 | Mona Sans | 15（编号 12） | 600，大写，字距 +1.6 | ①②③④，当前章节展开显示名称 |

- 都是 OFL 许可，字体文件和许可证放在 `template/public/fonts/`。
- 加载方式是 FontFace 加 `delayRender`。可变字体要声明 `stretch: "75% 125%"`。
- Mona Sans 一个字族覆盖了标题、界面和数字：宽度轴给大数字加宽，标签用窄一点的宽度，这样不用再引第三套无衬线。

## 4. 动效语言（`motion.tsx`）

| 名字 | 值 | 用在哪 |
|---|---|---|
| `EASE.out` | bezier(0.16, 1, 0.3, 1) | 所有入场：文字、卡片、条形 |
| `EASE.inOut` | bezier(0.65, 0, 0.35, 1) | 镜头运动、同一对象跨位置移动 |
| `EASE.in` | bezier(0.7, 0, 0.84, 0) | 退场 |
| `EASE.snap` | bezier(0.2, 0.9, 0.1, 1) | 小标签、芯片 |
| `DUR` | micro 0.22 / short 0.45 / base 0.7 / long 1.1 秒 | |
| `STAGGER` | 逐字 0.025 / 逐词 0.055 / 逐项 0.12 秒 | 片名逐词用 0.09 |

规则：

- 弹簧不许回弹（官方建议 `Easing.spring({damping: 200})`）。
- 缩放类动画用 `output: 'perceptual-scale'`。
- 全部由帧驱动，禁止 CSS transition。

## 5. 组件清单

| 组件 | 做什么 | 要点 |
|---|---|---|
| `RevealText` | 逐词遮罩上浮，模糊由 8px 收到 0 | 每个词 `overflow:hidden`，用 `translateY` 从 55% 回到 0 |
| `RevealNumber` | 数字逐位升起 | 不做滚动计数，滚动数字会抖 |
| `BigNumber` | 大数字居中亮出，再飞进对比条的数值位置 | 到达后条形自己的数值接管（`valueAt`），同屏不重复出现指标名 |
| `Gather` | 2×2 分析画板：镜头推近当前格，其余压到 32%，最后拉远看全局 | 推近倍数 1.82，格内缩放 0.47 |
| `Tag` | 3D 投影到屏幕上的 HUD 标签 | 26px 引线加端点光点，标签不遮挡轨迹 |
| `Caption` | 字幕逐词点亮 | 已念的词 100%，没念到的 58%，仍能提前读完整句 |
| `SectionTag` | 章节进度 | 当前章节展开名称 |
| `ChapterLeak` | 章节交界的漏光 | `@remotion/effects/light-leak`，screen 混合，不透明度 0.2（0.55 时整屏被染青，太重） |
| `FilmTexture` | 全片胶片颗粒和暗角 | 颗粒 5%，overlay 混合；暗角 0.55 |
| `Sweep` | 卡片或条形上掠过一道高光 | 0.9 秒 |
| `MethodFig` | 论文框架图和 3D 交替讲模块 | 先在图上定位并点名，再切 3D 演示；m1 整图时聚光依次扫过各模块；图隐藏期间预先平移到下一个模块 |
| `FigCard` 聚光 | 论文图的聚焦区域外压暗 50%，青色描边 | `focus` 里 `r` 管视角，`hl` 管聚光；图 3 用两两一组取景，只亮当前那一格 |
| `Leaderboard` | 结果章开场用主表全部方法的数轴，大数字从本方法的点里长出 | 同一对象延续：数轴上的点、大数字、条形的数值是同一个东西 |
| `RankPanel` 聚焦 | 几十条候选细条收成 A、B1、B2、B3 四行粗条 | 用连续排名（sigmoid 求和），分数交叉时两行平滑换位 |
| 两两比较图 | 菱形节点加两两连线和 Δr 标记，引线连回 3D 轨迹 | 3D 里点位挤在一起时，把关系画到 2D 图上，用引线连回 3D |

## 6. 3D 镜头规则

- **镜头不停**：所有镜头叠加手持漂移（幅度 0.35–0.7m，几个正弦频率错开）；车道线、路灯、桥墩随行驶滚动（13 m/s）。
- **地平线**：放在画面上方约四分之一处，远景层（天际线、山）放成 3D 片，让视差自然产生。
- **镜头移动**：关键帧之间用 easeIO；冷开场是低机位跟车，再升镜接片名。
- **轨迹**：用三层条带（色晕、色芯、白高光）加上流动光点。深色底可以用加色混合，浅色底只能正常混合，否则会冲白。

## 7. 配音与声音

- **合成方式**：**按段落整段合成**（默认 Edge TTS；Gemini TTS 还能每段配一条导演提示，例如问题段营造悬念、结果段念数字前停顿）。段内语气才连贯。
- **停顿**：不切句、不统一压停顿。整段 take 直接上时间轴，只把超过约 0.95 秒的停顿从中间截短（`assemble_natural.py`），句前句后的换气声都保留。统一压到 0.3 秒左右会让句间停顿比句内还短，听起来赶，而且削掉换气声会出现嘶声和咔哒声。
- **导演提示里写明**：不要气泡音（vocal fry），句尾音高要托住；只在标点处停顿，主语和谓语之间、介词后面不停。
- **音质**：从 TTS 原始 PCM 到成片只编码一次。多次转 MP3 会让齿音发糊，听起来像“电音”。
- **缩写**：在 `say` 字段里写成拼读，比如 `X-Y-Z`、`C-V-P-R`；字幕仍用 `text` 字段的原文。
- **配乐**：用一首 CC BY 的曲子做底，片尾或说明里要署名。用手动包络（`mix_all.py`），不用侧链压缩：压缩器在人声出来之后才反应，第一个字上会听到琴声突然掉下去。手动包络在人声前 0.8 秒开始压，句间短停顿不抬，章节间隔里抬起来做转场。人声下的配乐比人声低约 20 dB，30 dB 就基本听不到了。保留立体声。
- **音效**：本片最终不用合成音效。正弦波铺垫听起来像电流声，噪声扫频像静电，数字落定的叮声突兀。转场交给配乐的起伏。

## 8. 禁忌

| 禁忌 | 例子 |
|---|---|
| 大数字加霓虹外发光 | 像游戏缩略图 |
| 没有数据的空坐标轴先挂在画面上 | 坐标轴必须和条形一起出现 |
| 同一个指标名同屏出现两次 | 标题里一次、大数字下面又一次 |
| 把上一张图缩成角落里看不清的缩略图 | 像 Zoom 共享屏幕 |
| 默认 Tailwind 原色、会回弹的弹簧、800 以上的展示字重 | |
| 防御性小字 | "示意值""非本系统实测"一类的脚注 |
| 不和作者确认就删掉核心框架图或模块名 | 粗版的教训 |
| 每改一轮就渲染全片 | 迭代用静帧，全片要作者点头 |

## 8.5 评审循环

1. 按固定步长抽帧拼成联系表（`qa_video_audit.py` 会出一张，也可以自己写一个 `Sampler` 合成）。全片按 3 秒一帧，75 帧大约 40 秒就能出来。
2. 联系表切成 3 张，交给没参与写代码的另一家模型做设计评审，要求按影响排序、最多 20 条，每条给出时间点和具体改法。
3. 主控逐条核对后分三类：采纳、已解决、不采纳。不采纳的包括编造的分数、越过红线的说法，以及和正文不一致的计数。
4. 改完只抽有改动的时间段出密集联系表验证，然后进入下一轮。

## 8.6 第二、三轮评审的经验

- **动效要看视频，不能只看静帧。** 出 15–20 秒的短样片（`Clip` 合成加 `--frames`），交给能看视频的模型实际观看。飞行路线撞到别的标签、片名和旁白之间的空等、字幕抢先淡入、配乐一起一落像在"喘"，这些只有看动态才发现得了。
- **剪停顿只能在真实静音处下刀。** whisper 的词边界不可信，它给数字的结束时间偏早，照着剪会吃掉 ".3" 这类字音。现在的 `assemble_natural.py` 按 −42 dBFS 的能量判断静音；改完逐句回听核对。
- **同一对象跨镜头飞行时，走"先落后移"的弧线**，避免横穿其他行的标签。被飞过的那个标签延后出现。
- **条形图按旁白顺序出现时，三行先用虚线占位**，免得布局看起来在上移。
- **念到次要指标时**，把主图表压到一半亮度，给次要卡片加描边，把视线引过去。
- **音效**：风声用低通粉红噪声，不要共振扫频，并在人声开口前 0.25 秒结束；玻璃音要有 600–1200 Hz 的基音，落在两个词之间的缝里；低频铺垫要叠 150–300 Hz 的泛音，否则小喇叭听不见；配乐压低后的恢复时间设到 1.6 秒左右，避免一起一落。

## 8.7 第四、五轮的经验

- **论文图每张至少停 4–5 秒。** 放大的模块图只停 2.5 秒，看起来"切得匆忙"。做法：在该句前面加约 1 秒停顿（`assemble_natural.py` 的 `EXTRA`），让图在停顿里先出现，再晚一点切回 3D。
- **深色底上的字要够亮。** 字幕没念到的词不低于 88% 亮度，次要文字用 `#B8C4D4`，不要用 `#94A3B8`。Source Serif 字重 460。
- **一排小格子要设 `flexShrink: 0`。** 给一排格子条加了内边距底卡后，flex 把几十个格子压窄了约 2%，越往右偏得越多，绿色曲线落到了隔壁格子。凡是要跟连线对齐的元素，都按像素定宽、不许压缩，改完出 1.5 倍静帧核对落点。
- **图卡进出先压暗再切。** 白底论文图直接和深色 3D 叠化，会出现双重曝光。卡片要比暗幕早约 0.3 秒消失。
- **TTS 吞音用拼读加逗号解决。** 某个短语连续重试 4 次都被吞掉一个音，在 `say` 里加一个逗号断开，一次就好了。字幕仍用原文。

## 9. 流程

1. **定风格**：先让生图模型出 3–4 张关键镜头的风格帧，定下视觉标准。被否决的风格保留一个开关，不删代码（`theme.ts` 的 `LOOK`）。
2. **需要素材时**：再让生图模型出可合成的层，背景要求纯色，然后用抠图脚本（浅色底）或亮度转透明（深色底）转成透明 PNG。
3. **改完验证**：每次改完在关键时间点出静帧，拼成联系表自查。设计评审可以交给能看图也能听音频的另一家模型。
4. **出全片**：只在作者点头时，或者交付节点渲染 1080p 全片（`--scale=1.5`）。
