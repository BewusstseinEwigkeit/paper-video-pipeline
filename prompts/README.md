# 提示词与任务书模板

把尖括号里的内容换成自己的。提示词正文用英文，各家模型都能稳定执行；审查类提示词交给没参与写代码的另一家模型。

| 文件 | 用在哪一步 | 交给谁 |
|---|---|---|
| `01-读论文定分镜.md` | 开工：读论文、出旁白初稿和分镜表 | 主控 |
| `02-章节任务书.md` | 派活：一个章节的画面实现 | 写代码的模型 |
| `03-设计系统评审.md` | 定风格：字体、动效、配色体系 | 能看图的另一家模型 |
| `04-联系表审片.md` | 每轮迭代：抽帧联系表逐帧挑问题 | 能看图的另一家模型 |
| `05-动态样片审查.md` | 动效和音画同步：看 15 到 40 秒带声样片 | 能看视频、听音频的模型 |
| `06-配音试听.md` | 选音色、比较两条配音、检查混音 | 能听音频的模型 |

联系表用 `qa_video_audit.py --sheet` 出，或者渲染 `Sampler` 合成（见 `template/src/kit/Sampler.tsx`）。样片用 `Clip` 合成：`npx remotion render Clip out/clip.mp4 --props='{"from":26}' --frames=0-449`。
