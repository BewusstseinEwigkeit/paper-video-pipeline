# 章节任务书

主控派给写代码模型的任务书。一个章节一份，几份可以并行。

```markdown
# 任务：<章节名>（<行 id 范围，如 m1-m4>）

## 目标
<这一章要讲清楚什么；对应分镜表的哪几行>

## 只许改
- src/film/<Chapter>.tsx（新建）以及 src/film/Scenes.tsx 里挂载它的一行
- 其他文件一律不动

## 只读
- public/audio/vo.wav、public/audio/final.wav、src/film/data/vo.ts（时间轴由旁白生成，不许改）
- src/film/theme.ts、motion.tsx、Shell.tsx（规范与公共组件，只调用不修改）

## 硬约束
1. 画面时间只用 at("<行 id>", "<旁白里的词>")，不写秒数。
2. 必须出现：<论文图路径，如 public/figs/fig2.png> 和模块名 <A、B、C>；不许删图。
3. 上屏数字只用下表，逐条照抄：
   | 数字 | 出处 |
   |---|---|
   | <48.2> | <Table 1, Ours, metric X> |
4. 不放防御性小字（“示意值”“非本系统实测”之类）；示意图不标数字。
5. 可用组件：src/kit/ 下的 FigCard（论文图聚焦）、Tag、Axis/Bar、BigNumber；规范见 docs/02-字体与动效规范.md。

## 验收（退出前自己跑通）
- npx tsc --noEmit
- python -X utf8 <PVP>/tools/check_anchors.py src/film src/film/data/vo.ts（0 bad、0 warnings）
- 每个关键词时刻出一张静帧：npx remotion still Full out/check/<名>.png --frame=<帧号>，并列出帧号
- 写 REPORT.md：改了哪些文件、每个视觉节拍挂在哪个词上、静帧路径
```
